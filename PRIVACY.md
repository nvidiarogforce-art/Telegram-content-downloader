# Privacy Policy

Effective: 24 August 2026

Telegram Media Saver does not collect, sell, transmit, or retain personal data, browsing history, Telegram messages, or downloaded media.

The extension runs only on `https://web.telegram.org/*`. It reads rendered page elements solely to identify media the user can already access and to perform a user-requested download. Extension preferences such as enabled state and download folder are saved with Chrome's Storage API. Media URLs are passed locally to Chrome's Downloads API; page-local blob data stays in the Telegram tab.

The extension contains no analytics, advertising SDK, remote code, telemetry, or external extension backend. Chrome and Telegram may process data under their own policies as part of their normal browser and web-service operation.

Questions or security reports can be submitted through this repository's GitHub Issues page without including private Telegram content.
